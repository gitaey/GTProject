# 코드 설명 규칙

코드를 새로 작성하거나 수정할 때는, 그 코드가 **무엇을 왜 하는지** 초등학생도 이해할 수 있을 만큼
쉬운 한국어로 설명한다.

- 전문 용어(트랜잭션, 비동기, 프록시, 배치 처리 등)를 쓸 때는 바로 옆에 일상적인 비유나
  쉬운 말로 한 번 더 풀어서 설명한다.
  예: "비동기(=일을 시켜놓고 기다리지 않고 다른 일 먼저 하는 것)"
- "이 코드가 왜 필요한지" → "무슨 문제를 막아주는지" → "어떻게 동작하는지" 순서로 짧게 설명한다.
- 코드 자체(주석 포함)는 기존 컨벤션대로 간결하게 유지하고, **쉬운 설명은 코드 블록 앞뒤의
  일반 텍스트로** 덧붙인다 (코드 안에 장황한 주석을 넣지 않는다).
- 복잡한 버그를 고쳤을 때는 "원래 뭐가 문제였는지" → "왜 그런 문제가 생겼는지" → "어떻게
  고쳤는지"를 초등학생에게 이야기하듯 순서대로 설명한다.
